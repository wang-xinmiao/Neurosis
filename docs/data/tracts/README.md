# White-matter tractography demo data

`yeh2022.trx` is the simplified population-based tract connectome used by the
NiiVue tractography demos:

- Source: https://github.com/niivue/niivue/blob/main/packages/niivue/demos/images/yeh2022.trx
- NiiVue demo citation: Yeh et al., PMID: 35995773
- SHA-256: `A1F9047AAEFFF4C350988E2113A9AEA661DFC876E9B4DDA3A0300F8DA3BD363A`

The file contains grouped streamlines such as AF, CB, CST, ILF, SLF, UF, CC,
and IFOF for the left and/or right hemisphere. It is included for scientific
visualization and teaching demonstrations. Probabilistic tractography does not
prove a direct one-to-one anatomical connection for an individual subject and
must not be interpreted as a clinical diagnosis.
